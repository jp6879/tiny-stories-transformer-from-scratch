# Transformer from Scratch

A GPT-style language model built entirely from scratch in PyTorch — no HuggingFace transformers, no pretrained weights. Just raw matrix multiplications.

Trained on [TinyStories](https://huggingface.co/datasets/roneneldan/TinyStories), a dataset of short children's stories generated by GPT-4. The model learns to write its own stories, with... mixed results.

## How it works

Everything is implemented from first principles:

- **BPE Tokenizer** — learns subword merges from the training corpus (no pretrained tokenizer)
- **Positional Embedding** — sinusoidal encoding from "Attention Is All You Need"
- **Multi-Head Self-Attention** — Q/K/V projections, scaled dot-product attention, causal masking
- **Feed-Forward Network** — two linear layers with GELU activation and 4x expansion
- **Transformer Block** — pre-normalization (LayerNorm → sublayer → residual)
- **GPT Model** — stacks N blocks, adds a final LayerNorm and linear head for next-token prediction

## Usage

### Train

```bash
python train.py
```

This will:
1. Download a subset of TinyStories from HuggingFace
2. Train a BPE tokenizer on the corpus
3. Train the GPT model
4. Save the best checkpoint to `checkpoints/`
5. Generate a sample at the end

Edit `configurations/config.json` to change hyperparameters.

### Generate

```bash
python generate.py --prompt "Once upon a time"
python generate.py --prompt "The dragon was" --length 300 --temperature 0.6
python generate.py --prompt "A boy named Tim" --length 200 --top-k 30
```

| Flag | Default | Description |
|------|---------|-------------|
| `--prompt` | *required* | Starting text |
| `--length` | 200 | Tokens to generate |
| `--temperature` | 0.8 | Lower = more focused |
| `--top-k` | 50 | Limits sampling to top-k tokens |
| `--checkpoint` | `checkpoints/gpt_model.pt` | Model path |
| `--tokenizer` | `checkpoints/tokenizer` | Tokenizer path |

## Configuration

All hyperparameters live in `configurations/config.json`:

```json
{
  "vocab_size": 2048,
  "embedding_dim": 256,
  "num_heads": 8,
  "num_layers": 6,
  "seq_len": 256,
  "batch_size": 16,
  "epochs": 15,
  "lr": 3e-4,
  "dropout": 0.1,
  "num_train_stories": 50000,
  "num_val_stories": 5000,
  "checkpoint_dir": "checkpoints"
}
```
